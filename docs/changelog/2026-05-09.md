### What shipped

**New endpoint**: `GET /forex/historical?base={ISO3}&quote={ISO3}&date={YYYY-MM-DD}`
- Auth: Supabase JWT required
- Rate limit: 60/minute per IP
- Cache-first: `forex_rate_history` table (write-through, permanent, no TTL)
- Primary: ECB SDW EUR-pivot with 7-day walk-back range query
- Fallback: yfinance `{BASE}{QUOTE}=X.history()` with 7-day walk-back
- Returns: `{base, quote, date, rate, source, actual_date}`
- 400 on bad params, 404 on both upstreams empty

**New service module**: `services/forex_history.py`
- Deep module hiding ECB + yfinance + walk-back + cache complexity
- Public API: `resolve_historical_rate(base, quote, date) → ForexRateResult | None`
- EUR-pivot formula: `rate(base, quote) = ecb_rate(quote) / ecb_rate(base)` (ecb_rate(EUR)=1)

**New DB migration**: `supabase/migrations/20260509120100_forex_rate_history.sql`
- Table `forex_rate_history` with composite PK `(base_currency, quote_currency, rate_date)`
- RLS: SELECT for authenticated, INSERT/UPDATE for service_role only
- Immutable once written (ON CONFLICT DO NOTHING semantics)

**Tests**: 48 new pytest golden cases
- 11 EUR-pivot math unit tests (pure, no I/O)
- 5 ECB HTTP adapter tests (mocked at boundary)
- 3 yfinance adapter tests (mocked at boundary)
- 5 resolve_historical_rate integration tests (cache/ECB/yfinance/fallback paths)
- 7 endpoint tests (200/400/401/404 paths)
- 16 parametrized golden cases via `pytest.mark.parametrize` (all cross-combos)
- 1 founder reconstruction case (XAGCHF=X buy price math)
